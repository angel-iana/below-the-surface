Purpose

Three commitments

Information about the condition of infrastructure exists, but it is scattered across audit reports, registers, permits and statistics. This project brings it together in one place and holds every entry to three commitments.

Verifiable

Every fact leads back to its source

Each value carries its document, page and exact sentence, so anyone can check it. Facts are kept apart from interpretation.

Quality-checked

Checked before it is shown

Every fact has a stated confidence level. Unverified or conflicting facts are never published, limits are stated, and corrections are kept on record.

Quality

How much each fact can be trusted

Each fact carries a confidence level, and only checked facts reach a public report. Select a level for an example.

The quality cycle

  1. Automatic checks on every batchAnything that fails is set aside with the reason. Nothing is deleted.
  2. Human verificationThe first batch of any new document type is checked in full; after that, a 10% sample.
  3. Monthly source reviewLinks, content changes, licences and access rules are re-checked every month.
  4. Corrections are recordedRevised values sit next to the originals, with the date and reason.

Sources and attribution

Facts come from public documents and official open data published by Romanian and European public bodies. Each published fact names its source, document, page and date. The underlying facts belong to no one; the selection, verification and presentation are this project's work.

Accuracy and limits

Information is provided as published by the original sources and checked to the confidence level shown next to it. It is not an engineering assessment of any asset and must not be used as one. Where sources are incomplete or disagree, this is stated.

Corrections

If you find an error, it will be checked against the source. Corrected values are kept next to the original, with the date and the reason, so the history of every fact stays visible. A public corrections register is planned.

Privacy

The project records no personal data about individuals named in public documents. This site has no accounts, forms, cookies or analytics of its own.
